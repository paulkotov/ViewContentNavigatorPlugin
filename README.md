# View Content Navigator — плагин Revit 2022

Навигатор по всем категориям и элементам модели Revit. По нажатию кнопки на ленте
создаётся **временный 3D-вид**, на котором видны все категории и элементы, и открывается
модальное-независимое (modeless) окно WPF с деревом:

```
Категория Revit
└── Семейство (present in view)
    └── Экземпляр            ← опционально (переключатель «Экземпляры»)
```

У каждого узла дерева:

- **чекбокс** — скрыть/показать элементы на активном (навигаторском) виде;
- **цвет** — переопределение графики (проекция + поверхность solid fill) на этом виде.

Все изменения применяются **на лету** (переключатель «Авто»). Есть кнопки
`Скрыть`, `Показать`, `Цвет`, `Сброс цвета`, палитра быстрых цветов и произвольный
выбор цвета (`…`). Настройки (видимость + цвета) и сам вид можно сохранить.

## Технологии

- C# / .NET Framework 4.8 (x64) — как во всех Revit 2022–2024.
- Revit API (`IExternalApplication` + `IExternalCommand`).
- WPF + **MVVM** без сторонних MVVM-фреймворков.

## Архитектура

| Слой | Назначение |
|------|------------|
| `Application/` | Точки входа: лента (`NavigatorApplication`), команда (`ShowNavigatorCommand`), доступность кнопки. |
| `Revit/` | `RevitTask` — единый `ExternalEvent`, превращающий вызовы API в `async/await`. Это ключ к безопасной работе из modeless-окна. |
| `Services/` | `ViewContentService` (создание вида, сканирование, скрытие/показ, цвет, сохранение/удаление вида) и `ExtensibleStorageSettingsStore` (настройки в JSON внутри `.rvt` через Extensible Storage). |
| `Models/` | POCO: палитра, DTO настроек, снимок вида, `NodeState`. |
| `ViewModels/` | `NavigatorViewModel` (координатор) + дерево узлов с трёх-состоянием чекбоксов (`TreeNodeViewModel`, `Category/Family/Instance`). |
| `Views/` | `NavigatorWindow.xaml` + конвертеры. Тонкий code-behind (только проброс выбранного узла и закрытия). |

### Почему `ExternalEvent`

Modeless-окно живёт в потоке WPF-диспетчера и **не имеет права** обращаться к Revit API
напрямую. Любое чтение/запись модели проходит через `IRevitTask.Run(...)`, который ставит
делегат в очередь единственного `ExternalEvent` и выполняет его в контексте Revit. Все
изменения модели идут в транзакциях внутри `ViewContentService`.

### Оптимизация перерисовок

- `ObservableObject.SetProperty` поднимает `PropertyChanged` только при реальном изменении.
- Каскад чекбоксов «родитель ⇄ дети» обходится один раз и генерирует **одну** транзакцию
  на действие пользователя (а не по одной на каждый элемент).
- Узлы-экземпляры создаются лениво (только при включённом переключателе «Экземпляры»).
- `TreeView` виртуализируется (`VirtualizingStackPanel` + recycling).

## Сборка

Требуется Windows с установленным Revit 2022 и .NET Framework 4.8 Developer Pack.

```powershell
# из корня репозитория
dotnet build ViewContentNavigator.sln -c Release
# или сразу разложить в папку аддинов Revit:
dotnet build ViewContentNavigator.sln -c Release /p:DeployToRevit=true
```

Если Revit установлен нестандартно, укажите путь к API:

```powershell
dotnet build -c Release /p:RevitVersion=2022 /p:RevitApiDir="D:\Autodesk\Revit 2022"
```

## Установка вручную

1. Скопируйте `ViewContentNavigator.dll` (+ `.pdb`) в
   `%APPDATA%\Autodesk\Revit\Addins\2022\ViewContentNavigator\`.
2. Скопируйте `ViewContentNavigator.addin` в
   `%APPDATA%\Autodesk\Revit\Addins\2022\`.
3. Запустите Revit → вкладка **«Навигатор»** → **«Навигатор содержимого»**.

## Использование

1. Откройте модель, нажмите кнопку на ленте — создаётся временный 3D-вид и открывается окно.
2. Ставьте/снимайте галочки и назначайте цвета — вид меняется мгновенно.
3. Включите **«Экземпляры»**, чтобы раскрыть отдельные элементы под семействами и назначать им индивидуальные цвета.
4. `Сохранить настройки` — записывает конфигурацию (видимость + цвета категорий, семейств и отдельных экземпляров) прямо в `.rvt` через Extensible Storage; при следующем открытии модели настройки подхватываются автоматически.
5. `Сохранить вид` — делает временный вид постоянным (иначе он удаляется при закрытии окна).
